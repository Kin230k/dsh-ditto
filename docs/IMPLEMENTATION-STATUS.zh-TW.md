原型提供宣告式配方、樣本／整批預覽、逐檔修正、非破壞式複製、持久化狀態、配方保存、本機工作台與五個 DSH 工具。完整結果見[驗證紀錄](VALIDATION.zh-TW.md)。

## 驗收重點

- 真實原檔 → 預覽 → 修正 → 複製 → 逐項結果；原檔內容一致。
- 重名、Windows 大小寫衝突、來源變動、路徑跳脫與 symlink/junction 不可造成靜默覆寫。
- 未保存編輯、舊 digest、同批重複執行與重啟後恢復的狀態清楚。
- 可保存並重新載入配方；M0 的宣告式規則不宣稱從範例學會語意。
- DSH 真實公開 API 的註冊／工具執行證據；mock 測試不能冒充宿主相容。

對外發布、使用者日常 DSH 升級、完整 CLI profile 開機／模型呼叫及 M1 語意配方尚未包含在本輪交付。這個版本證明工程流程可行，沒有證明市場留存或「爆款」。
